# Decision Log

> **Status: Curated public projection.**

A compact workflow for recording material decisions, alternatives, consequences, follow-ups, and review triggers without turning routine activity into a ledger.

## Use it

Place `SKILL.md` in the skill location supported by the host. Project instructions should name the canonical decision-log path. If they do not, prefer a repository-local `DECISIONS.md` for project decisions and ask before creating a cross-project record.

## Projection boundary

The public workflow is deliberately neutral about task trackers, memory systems, organizations, and global home-directory layout. It does not include any real decision records.

## Validation

The repository validates the skill's frontmatter and lifecycle metadata. The workflow itself still depends on human judgment about what is material and where the durable record belongs.
