# ADHD Helper

> **Status: Current public snapshot.**

A lightweight workflow scaffold for reducing working-memory load, scope creep, open loops, and restart friction during complex Codex coding work.

It is not medical advice. It is intended for broad, ambiguous, interruption-prone, or review-heavy tasks—not tiny edits.

## Core pattern

- Keep one active implementation lane.
- Define acceptance before editing.
- Park distracting ideas instead of chasing them.
- Make state restartable when the task is long.
- Run the narrowest relevant verification.
- Close with changed, verified, open loops, and next safe action.

## Claim limits

The package has structural validation only. It does not claim clinical effectiveness or universal workflow fit. Repository-local session state should remain uncommitted unless the user explicitly chooses otherwise.
